# Day 08 – Network Challenge | Network Fundamentals

## 📌 Project Overview

As part of my Cybersecurity & Ethical Hacking Internship at NETWORKWALKS, I completed Day 08 Network Challenge, focusing on practical network identification, DNS investigation, and network path analysis using Windows Command Prompt.

This task helped me understand how devices communicate across networks, how domain names are resolved into IP addresses, and how network traffic travels towards a destination.

## 🎯 Tasks Completed

### Task 01 – Network Identity
Collected and analyzed network configuration details using:

```cmd
ipconfig
ipconfig /all
```

**Information Identified:**
- Network Adapter Details
- IPv4 Address
- Subnet Mask
- Default Gateway
- DNS Server
- MAC / Physical Address
- DHCP Configuration

### Task 02 – DNS Investigation

Command:

```cmd
nslookup google.com
```

**Key Learning:**
- Understanding Domain Name System (DNS).
- Resolving domain names into IP addresses.
- Identifying the DNS server responding to queries.
- Understanding DNS name resolution.

### Task 03 – Network Path Investigation

Command:

```cmd
tracert google.com
```

**Key Learning:**
- Understanding network routing paths.
- Identifying intermediate network hops.
- Understanding the role of the default gateway.
- Analyzing connectivity and possible network delays.

## 🛠️ Tools & Technologies

- Windows Command Prompt (CMD)
- IP Configuration Utilities
- NSLookup
- Traceroute (TRACERT)
- TCP/IP Networking
